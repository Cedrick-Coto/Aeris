## 3. Propiedad arquitectónica respaldada

> La infraestructura permanece estable mientras el comportamiento se intercambia mediante contratos bien definidos.

- **Soporte**: evidencia acumulativa de cuatro experimentos independientes sobre subsistemas distintos (Attention, Reasoning, Memory Retrieval, Planning), en línea con el Axioma A2 (variabilidad en el modelo, no en la infraestructura).
- **Alcance**: **no** es una afirmación universal para todos los subsistemas. Es una hipótesis respaldada por múltiples experimentos independientes sobre los subsistemas validados; cada subsistema futuro requiere su propia evidencia.
- **Coste de intercambio**: 0 contratos nuevos, 0 ADRs, 0 cambios de infraestructura durante 3X.3.2–3X.3.4. Dos reconciliaciones documentales alinearon contratos con la implementación existente (CONTRACT-REASONING v0.3, CONTRACT-PLANNING v0.3); ninguna modificó el contrato para acomodar una estrategia.
